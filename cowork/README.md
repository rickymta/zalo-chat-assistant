# Thư mục `cowork/` — bộ chỉ dẫn cho Claude Cowork

Bộ tài liệu này được **tự động chép** vào mỗi gói xuất (thư mục `huong-dan/` trong gói) để gói tự đủ: người dùng chỉ cần
mở Claude Cowork ở thư mục gói và nhắn *"Đọc `huong-dan/00-chi-dan-cho-claude.md` rồi tổng hợp các hội thoại đang chờ
trả lời và đề xuất phản hồi."*

| File | Nội dung |
|---|---|
| `00-chi-dan-cho-claude.md` (= `CLAUDE.md`) | Vai trò, thứ tự đọc, quy trình, điều cấm, giọng văn |
| `01-cau-truc-du-lieu.md` | Cấu trúc gói, cách đọc file hội thoại, giới hạn dữ liệu |
| `02-quy-trinh-tong-hop.md` | Khung rút thông tin, xếp ưu tiên P1/P2/P3, tự soát |
| `03-quy-tac-de-xuat-phan-hoi.md` | Quy tắc viết câu trả lời: giá, lịch, y khoa, khiếu nại, câu mẫu |
| `04-mau-dau-ra.md` | Mẫu bảng ưu tiên, phiếu từng hội thoại, báo cáo ngày |
| `05-thong-tin-meddental.md` | Liên hệ, 8 cơ sở, con số được phép, giọng văn |
| `06-vi-du-hoan-chinh.md` | Một ví dụ từ file hội thoại đến phiếu đề xuất |
| `du-lieu/` | Bản sao `dich-vu.md`, `bang-gia-08-2023.md`, `bac-si.md` từ repo marketing — cập nhật bằng `scripts/sync-brand-docs.sh` |

Sửa tài liệu ở đây ⇒ mọi gói xuất **sau đó** nhận bản mới (gói đã xuất giữ bản cũ). Với bản ứng dụng `.app`, tài liệu
nằm trong gói ứng dụng — sửa xong phải đóng gói lại (`npm run dist`).
